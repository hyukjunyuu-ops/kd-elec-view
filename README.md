# 전기계통 관리 (보기용 사이트)

종근당 천안공장 전기계통 관리 앱의 **화면 파일만** 올려 둔 공개 레포예요.
**실제 계통 데이터는 들어 있지 않아요.**

## 핸드폰·PC에서 보기
1. 이 사이트 주소를 열어요 (GitHub Pages).
2. 처음 한 번 **[📁 파일] → 📂 백업 불러오기**로 백업 JSON 파일을 넣어요.
3. 그다음부터는 그 기기(브라우저)에 저장돼서 바로 열려요. 새 백업을 받으면 다시 불러오면 돼요.

화면 코드는 비공개 작업 레포에서 `scripts/publish-view.sh`로 복사해 와요. 여기서 직접 고치지 마세요.
